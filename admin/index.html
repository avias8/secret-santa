Connect to the site

So the names save straight to the family page, this page needs a GitHub access token that can edit only the secret-santa repository. You do this once on this device.

  1. Open New fine-grained token on GitHub.
  2. Name it “Secret Santa”. Under Repository access pick Only select repositories → secret-santa.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Generate the token, copy it, and paste it here.

The token stays in this browser only. Anyone with it could edit this one repo, so don't share it.
